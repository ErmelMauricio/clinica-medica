## Definição do Sistema

### Qual é o objetivo do sistema?

O Sistema de Gestão de Agenda Para Clínica Médica tem como objetivo gerir o processo de agendamento de consultas, o cadastro e manutenção de dados dos pacientes e a gestão de agenda dos médicos.

### Quem utilizará o sistema?

O sistema será utilizado unicamente pleas Recepcionistas.

### Qual problema o sistema pretende resolver?

O sistema pretende resolver a lentidão e desorganização decorrente de controles de agendamento de consultas através de agendas físicas e também pretende eliminar conflitos de horários na agenda dos profissionais de saúde.
